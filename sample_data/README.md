# Sample data

Fictional demo documents ("Northwind Bank"), generated by `python -m app.scripts.make_sample_data` and loaded with `make seed`:

| File | Type | Content |
| --- | --- | --- |
| `sample_internal_kyc_data_policy.pdf` | policy | 5 pages: OVDs and proof of address, V-CIP, Aadhaar masking, risk categories, periodic updation, five-year retention, CTR/STR reporting, consent, vendor rules |
| `sample_digital_lending_policy.pdf` | policy | 4 pages: disbursal flows, Key Fact Statement, cooling-off period, fees, borrower data, grievance redressal, recovery practices |
| `sample_information_security_standard.pdf` | policy | 3 pages: access control, encryption, logging, backups, incident reporting, vendor security, exceptions |
| `sample_vendor_kyc_agreement.pdf` | contract | 11 clauses; clauses 3, 4, 5, 6 and 8 deliberately break the KYC policy (self-declared address, full Aadhaar storage, 12-month retention, sharing without consent, 72-hour breach notice) |

The evaluation test set (`eval/testset.json`) refers to these documents by filename and page.

You can add real public PDFs here too (for example the RBI Master Direction on KYC); they are gitignored. `make seed` ingests every PDF in this folder, as a contract if the filename contains "agreement" or "contract", otherwise as a policy.
